Start here

The 3.2 tutorial series is being recorded. Until then: the two films show 3.2 at work, and the steps on the right get you installed.

  1. Add two repositories in PixInsight (Resources › Manage Repositories):https://pixinsight.pimagicstudio.com/pm3/https://pixinsight.pimagicstudio.com/pisolver/
  2. Check for updates and restart PixInsight.
  3. Enter your licence key — switch to Expert mode for the Tools tab. The same key activates PiSolver.
  4. Install AstroMagic from the Tools tab: Install Plugin, then Install Actions.
